# WEB2-Expense-Tracker-App
Personal Expense Tracker – Manage expenses, income, and budgets with an interactive dashboard and authentification system. 

## Description 

*Expense Tracker* is a comprehensive web application that allows users to *track their income and expenses*, with the ability to *manage one-time or recurring expenses* and *attach receipts*. The goal is to help everyone *better manage their money in real time*.

---

## Project objective 

- Track *income*
- Manage *daily expenses*
- Plan *recurring expenses*
- Attach and view *receipts*
- Have a *clear view* of your financial situation in a dashboard 
- Track your monthly expenses 

--- 

## Tools and technologies 

### - Frontend :
React.js, React-router Tailwind CSS, Recharts, Axios

### - Backend :
Node.js + Express.js, Sequelize : ORM, PostgreSQL
 
---
## Prerequisites

Ensure that these tools are installed: PostgreSQL, Node.js
Create the database locally, then put the necessary details in the backend .env file, such as the password, username, host, database name, and database port, and *don't forget to put .env .gitignore*

---

## Steps to launch the project 

- Clone the project : 
git clone ```|https://github.com/RahJessica/WEB2-Expense-Tracker-App.git```
- cd WEB2-Expense-Tracker-App
- Launch the backend: 
    - cd backend
    - npm i 
    - node src/app.js
- Launch the frontend: 
    - cd frontend
    - npm i 
    - npm run dev
